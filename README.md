# Доменная адаптация для семантической сегментации

**[Открыть статью в PDF](paper/article.pdf)** · [Исходный текст](article.tex) · [Сборки GitHub Actions](https://github.com/k0rshz/misis-article-latex/actions/workflows/build.yml)

**Н. М. Коршунов**, кафедра инженерной кибернетики НИТУ «МИСиС». Черновик статьи для ПЗ-3 по дисциплине «Научное письмо и публикационная деятельность».

В работе рассматривается перенос модели сегментации с синтетических дорожных сцен GTA5 на фотографии Cityscapes. Во время обучения модели доступны маски классов для синтетических изображений и реальные изображения без разметки. В статье сопоставлены шесть способов использовать эти данные, разобраны опубликованные результаты и описан план собственного сравнения по mIoU и качеству отдельных классов.

## Работа с текстом

В [основном файле](article.tex) находятся название, аннотация, коды и ключевые слова. Текст разделён на [введение](sections/introduction.tex), [анализ работ](sections/related-work.tex), [постановку задачи](sections/problem.tex) и [описание методов](sections/methods.tex). В конце статьи приведён [список литературы](references.tex).

PDF в каталоге `paper/` соответствует редакции для ПЗ-3. При загрузке изменений GitHub Actions заново собирает статью и прикрепляет `article.pdf` к завершённому запуску. Для локальной сборки с установленным Tectonic выполните `make article`. Результат появится в `build/article.pdf`.

Статья оформлена в [шаблоне Р. Н. Садекова](https://github.com/sadekovlar/misis-article-latex). Условия распространения класса оформления приведены в [LICENSE](LICENSE).
